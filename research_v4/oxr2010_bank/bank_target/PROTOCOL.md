# Bank quote target: protocol fixed before fit

This is a separate prediction task on actual archived Halyk personal RUB **BANK SELL** quotes. q is **KZT paid for one RUB purchased from the bank**. Lower q is better for a customer buying RUB. It is not the bank BUY quote required for a customer selling RUB and it is not the RUB→KZT remittance execution price.

Each observation date s yields exactly one decision at noon Asia/Almaty on s+1 calendar day. The archive's effective date is reconstructed from ISO `date_at` in UTC using the historical Asia/Almaty zone, independently cross-checked against the API's epoch milliseconds. Conflicting values for the same local day are excluded in full. Positive finite quotes only; no daily interpolation. Quote availability is assumed to be local midnight on s+1; this is an explicit conservative proxy, not verified publication time. q_s is the latest observed quote, whose executability at decision time is unknown.

The horizon is the next five actual clean Halyk quote observations, not five calendar days and not CBR sessions. The label is their arithmetic mean, `future_mean_kzt_per_rub`. The regression target is `change_bps=10000*(future_mean/q_s-1)`; a persistence forecast predicts zero change. The binary target is `I(future_mean>q_s)`, representing a later increase in quoted RUB purchase cost. Positive values do not prove that executing at q_s was possible. Ties are target 0 and separately counted. A five-quote window exceeding 14 calendar days is excluded. Label availability is the last future quote's local effective date+1 calendar day. No unobserved final targets are filled.

Fixed models: prior-validation prevalence + zero-change persistence; prior-validation prevalence + prior-validation mean-change constant; bank-own-history HGB; CBR-history-only HGB; bank+CBR HGB; bank+CBR+OXR HGB. HGB classifier and regressor: depth2,120 trees,learning_rate0.05,min_samples_leaf40,L2=2,no early stopping,random_state1701. No hyperparameter search. Features use history only. Bank returns/ranks/volatility use actual quote updates; CBR KZT/RUB orientation is inverted to KZT/RUB and conservatively available effective date+1 day. OXR uses KZT/RUB and max(published_at,completed UTC day)+24h, as in the existing OXR contract. As-of joins have a seven-day maximum age; every model is evaluated on identical bank target dates, keeping missing source values as NaN.

Annual development cutoffs 2023/2024/2025 use all available bank-label training history from 2020 before a trailing twelve-month validation period. Train labels must mature strictly before validation start; validation labels strictly before cutoff. Classification Platt calibration uses that validation only. Regression is trained on the training block without test calibration. Development labels must also mature before the following year's start. January1,2026 and March1,2026 freezes are separate fits. March allows matured January/February2026 validation labels. They are compared both on their full available evaluation window and on common dates from March5,2026. The history was inspected previously, so 2026 is retrospective evidence even when excluded from fit/selection.

The primary incremental contrast is bank+CBR+OXR minus bank+CBR. All four feature arms are reported; no model is promoted based on 2026. A paired OXR start2018 versus start2010 control must have identical features and predictions after the feature warmup because all real bank labels begin in 2020. Longer OXR history cannot create missing bank labels.

Metrics: Brier/log loss/AUC, MAE/RMSE of future-mean percentage change in basis points, corresponding absolute KZT/RUB forecast errors, and skill against a **past-validation** prevalence baseline or zero-change persistence. No test-label prevalence is used as a trained baseline. Paired calendar-month bootstrap confidence intervals preserve shared market paths, resampling months rather than treating synthetic or feature rows as independent markets. Intervals condition on the frozen fitted models and do not correct for all past research.

Verification: raw epoch/ISO/local-day reconstruction and conflicts; exact source SHA; independently enumerated target windows and maturity; feature prefix invariance under poisoned future raw Halyk/CBR/OXR; cut-off fit invariance after flipping future/unmatured labels and future features; checkpoint prediction/calibration parity; same dates for all arms; OXR2010/2018 identity. Old V3/V4 files are read-only. Only this subdirectory is writable by this task.

Verification correction before final reporting: every raw RUB quote is on a 0.01 KZT grid. Exact integer ticks are used for target comparisons and zero-change ties. Independent Decimal enumeration caught three ties that naive floating arithmetic had incorrectly classified as positive; those labels are corrected, not assigned a tuned tolerance. The future-window density filter is an ex-post evaluation condition, not a deployable eligibility feature.
