В `output/` сохранены 85 HGB-моделей с калибратором, порогами, признаками, предсказаниями и квитанциями. Ни нейросетевые веса, ни нейросетевые прогнозы повторно не вычислялись. Источник OXR читается из неизменённого общего `../input_oxr_snapshot.csv`. История с 2018 года — усечение этого же нового файла, а не предыдущая версия поставщика.

Запуск из каталога `AlphaTransfer` на `/private/tmp/alphatransfer-tabm-venv/bin/python`:

```bash
python research_v4/oxr2010_bank/foundation/experiment.py --phase protocol
python research_v4/oxr2010_bank/foundation/experiment.py --phase development
python research_v4/oxr2010_bank/foundation/experiment.py --phase test
python research_v4/oxr2010_bank/foundation/assess.py
python research_v4/oxr2010_bank/foundation/verify.py
python research_v4/oxr2010_bank/foundation/write_report.py
```

Протокол содержит 15 первоначальных конфигураций; дополнение добавляет два однодневных контроля Halyk. Фактически исполняемый список из 17 вариантов сохранён в `experiment.py` и в квитанциях каждого обучения. Основной выбор по исследовательским данным не включает однодневные банковские контроли.

Каждая задержка доступности имеет отдельно обученную голову. Это сравнение обученных моделей с разными лагами, а не проверка отказа источника для фиксированной рабочей модели. Цель остаётся меткой NOW на курсах ЦБ; банковские архивы здесь являются признаками и не превращают результат в тест исполнения перевода.

После численного аудита добавлены 15 голов в `canonical/`: поздние OXR-признаки с 2018-09-01 взяты точно из представления с 2018 года, а настоящие ранние значения сохранены. Для трёх проверяемых конфигураций все вероятности и сигналы совпали с исходными. [Протокол](canonical/protocol.json), [результаты](canonical/summary.csv), [точное сравнение](canonical/reproduction_to_original.json). Общее количество обученных голов — 100; [объединённая проверка](final_verification.json) учитывает первоначальные и дополнительные эксперименты.
