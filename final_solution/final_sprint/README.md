# AlphaTransfer — выбранный профиль KZT

**tabm_periodic_kzt_120m_s2_kztcal**, 10 лет обучения, политика `cadence85_cd2`. Исполняемый исследовательский профиль со штатно свежими банковскими данными.2026: lift **1.505**, **29/33 недель**, **40 сигналов**, **+66.22 б.п.** к среднему дню;2025: lift1.5125 и45/51 недель.

Из корня AlphaTransfer:

```bash
/private/tmp/alphatransfer-tabm-venv/bin/python final_solution/final_sprint/predict.py
```

Результат: `output/predictions.csv`. `--as-of YYYY-MM-DD` ограничивает расчёт указанной датой; `--features` принимает таблицу признаков. Для последовательных непересекающихся блоков используйте `--state-out` и затем `--state-in`. Профиль требует все последовательные сессии и отклоняет пропуски/повторы. По умолчанию используется воспроизводимый исторический пример2026; актуальные признаки должны строиться по тому же временному контракту.

`model/` содержит веса, preprocessing и отдельную CLOSING-голову. NOW остаётся основным сценарием; CLOSING — дополнительная аннотация своего события на части NOW-контактов. Новых уведомлений она не создаёт. Профиль ничего не отправляет.

[Полный отчёт](../../research_v4/final_sprint/REPORT.md), [выбор](selection.json), [интервалы](selected_intervals.json). Отбор по2026 ретроспективный. Превосходство lift надV3 пока не доказано доверительным интервалом; метрики рассчитаны по официальному курсовому ориентиру KZT и не являются клиентской экономией. Дополнительные сбои источников сохранены как диагностика.
