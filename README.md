# AlphaTransfer — FX signal layer

Воспроизводимый сигнальный слой для коридоров RUB→TJS/UZS/KGS/AMD/KZT по
дневным официальным курсам ЦБ РФ. Значение ряда всегда нормализовано в
`rub_per_unit` — рублях за одну единицу валюты получателя. Меньшее значение
означает, что за ту же сумму в RUB получатель получает больше валюты.

## Быстрый запуск

Нужен Python 3.10+; у реализации нет внешних зависимостей.

```bash
python -m pip install -e .
alphatransfer download --start 2020-01-01 --end 2026-09-01 --output data/cbr_daily.csv
alphatransfer signals --input data/cbr_daily.csv --as-of 2026-09-01
alphatransfer backtest --input data/cbr_daily.csv --as-of 2026-09-01 --horizon 5 --walk-forward
alphatransfer backtest --input data/cbr_daily.csv --as-of 2026-09-01 --horizon 5 --model classical
```

Без установки пакета команды можно вызывать как `PYTHONPATH=src python -m
alphatransfer …`. Проверка: `PYTHONPATH=src python -m unittest discover -s
tests -v`.

## Что делает код

- `cbr.py` загружает публичный `XML_dynamic.asp` ЦБ РФ и сохраняет проверяемый
  CSV (`date,corridor,rub_per_unit,nominal,cbr_value`). Номинал из исходника
  делится до расчёта, поэтому, например, 100 AMD не принимаются за 1 AMD.
- `calendar.py` умеет строить календарный display-ряд с forward fill и флагом
  `is_publication_day`. Сигналы считают только реальные дни публикации: выходные
  и праздники не превращаются в фиктивные нулевые изменения.
- `engine.py` реализует моментум вниз, нижний перцентиль, разворот вверх,
  исторический календарный контекст и волатильность. Он возвращает единую
  таблицу: дата, коридор, индикатор, направление, сила, скорость, сценарий и
  фактические основания. Cooldown задан в днях публикации и подавляет серии.
- `ml.py` — объяснимый dependency-free классический ML: логистическая регрессия
  оценивает, является ли дата локальным минимумом в окне ±h по тем же признакам.
  Порог решения учитывает асимметрию: ложный «сейчас выгодно» в три раза дороже
  пропуска. Коэффициенты и порог включаются в JSON-результат.
- `backtest.py` считает hit rate, lift над случайным днём в том же периоде,
  выгоду в bps, частоту и кучность. Калибровка rules и ML выполняется
  walk-forward; случайный baseline ограничен тем же test/fold интервалом.

## Защита от заглядывания вперёд

`signal_at(quotes, T)` и `signals_as_of(quotes, T)` отбрасывают каждую строку
после T. Индикаторный цикл использует срезы, оканчивающиеся текущим днём.
Будущие цены допустимы только в `evaluate_events` для уже отправленных и уже
разрешившихся сообщений; в отчёте с `--as-of T` даже settlement не выходит за
T. ML обучается только на метках, у которых весь будущий горизонт уже наступил
до границы обучения.

`favourable_now` считается попаданием, когда курс в день сигнала не выше ни
одного из следующих `h` дней публикации. Для `window_closing` требуется рост
курса за `h` дней. Это две разные проверки, а не одна общая accuracy.

Курс ЦБ — публичный ориентир, не курс исполнения перевода в приложении: это
важное допущение для пилота, а не обещание клиенту.
